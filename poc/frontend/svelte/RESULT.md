# POC - svelte

## Usage

Run the `svelte` POC by doing `pnpm install`, `pnpm run build` then `pnpm run preview`.

You can then go to `http://localhost:4173/` on your browser.

## Ease of use

### Library itself

The library is pretty simple to use. The setup was quite intuitive using `pnpx sv create`.

The setup also installed TailwindCSS directly.

To use a "state", you just have to use a `$state` variable.

Classes are named using `class` property.

To store data from an input, you just need to "bind" it (`bind:value`).

### API call

Making an API call was pretty simple using the `fetch` API.
