# POC - Frontend

## Formalism

For each technology you might choose, create a folder named as such:
```
<framework / library>
```

As an example, the React framework, the folder to POC this technology will be: `react`.

## Application creation

Initialize the project, (remove everything from the template if needed) and integrate TailwindCSS into it.

Create a very simple TODO list app. Everything must stay client side.

When the client arrives on the page, do a simple request to `https://httpbin.org/anything` and display the user's IP (contained in the `origin` field) in the footer of the page.
Make sure the request is done client side (client component).

## Validation

To "validate" a POC, you **must** write about:
- is it easy to use? how easy was it to make the API call?
- is the documentation clear? is there a lot of documentation about it?
- does it have a wide ecosystem (lots of libraries to use)
- latest library release date, is it still currently supported?
- any recent security incidents?
