# POC - angular

## Usage

Run the `angular` POC by doing `npm install` then `npm run start`.

You can then go to `http://localhost:4200/` on your browser.

## Ease of use

### Library itself

The library is quite complicated to use. The setup itself was quite intuitive using `pnpx @angular/cli new`.

The setup also installed TailwindCSS directly.

Angular is OOP based, everything is based via classes.

To use a "state", you just have to use a `signal` variable.

Classes are named using `class` property.

To store data from an input, you just need to "event handle" it (`(input)`).

### API call

Making an API call needs to be done using the HttpClient.

You first need to "provide" it to the HttpClient. Then you can "inject" to the component.

Then you can use the `http` variable inside the class to make requests.

It isn't as straight forward as some other frontend frameworks.
