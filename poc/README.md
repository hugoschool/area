# POC - AREA Proof Of Concept

In this directory, we will explore a couple of directions for some parts of the AREA project.

## Validation

To "validate" each technology, you **must** produce a RESULT.md file.

The validation vary from section to section (example: `backend`'s `README.md` contains the validation of each technology).

For example, for the `backend/ts-express` technology, you must follow the `backend/README.md` file to "validate" each technology then create a document to recap everything asked to be "validated" in this technology inside `backend/ts-express/RESULT.md`.

## Choosing a tech stack

After each POC is done, the team will evaluate and produce a final file to determine which tech stack to choose.
